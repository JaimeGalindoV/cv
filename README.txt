CV web bilingüe

1. Abre index.html en Chrome, Edge o Firefox.
2. Usa el botón de idioma para cambiar entre inglés y español.
3. Pulsa Descargar PDF. Se genera un PDF tamaño carta con el contenido del idioma activo y se limita a una página.

La generación de PDF usa html2pdf.js desde CDN, por lo que se necesita conexión a internet. Si no carga, el sitio abre el diálogo de impresión del navegador.
